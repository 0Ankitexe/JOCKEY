# Requirements traceability

Status values distinguish Version 0 foundations, Version 1 syntax and the
complete Version 2 static checker, metadata, discovery and reports (T001–T093),
plus complete Version 3 compiler/fixture infrastructure (T001–T100).
Requirement status remains limited to the functionality explicitly described;
Version 2 completion does not implement later runtime or forensic requirements.
No operational, forensic, transport, endpoint or evasion capability is claimed.
The latest evidence is in [version-3-verification.md](version-3-verification.md).
Earlier MVP and Phases 4–5 checkpoints remain historical records. Completion of
Version 3 is limited to compiler infrastructure and synthetic fixture execution.

The [constitution](../.specify/memory/constitution.md) was first ratified as
version `1.0.0` on 2026-09-15. The [retrospective audit](constitution-audit.md)
maps its rules to Version 0/1 evidence and limitations. This governance update
does not advance any SIH implementation status. ADR-0006 records the adoption
and the alignment of Version 1 FR-036 with ADR-0005; all SIH-01 through SIH-24
rows below retain their product-version scope. The six Version 2 rows were advanced
only by the evidence in [version-2-verification.md](version-2-verification.md).

## Linux-first governance update — 2026-09-21

Constitution **1.1.0**, ADR-0013 and the [roadmap](linux-first-roadmap.md)
change future delivery order, not the implementation versions/statuses below.
Version 4 is deferred into Version 16; revised Version 5 owns shared foundations
and Linux collectors. Versions 6–15 deliver Linux first, then Version 16 completes
Windows and mixed-platform acceptance. No existing evidence is relabelled.
